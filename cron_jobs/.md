"""Create a program with two cron jobs
1. To insert data current unix timestamp into table every 1 minute.
2. To create a partition for values in the last 10 minutes and it should run every 10 mins."""


cron_jobs  ---- root directory

\logs ---- storing the log details

\config.py --- configuring the creadentials so that it can access the database user details

\db.py --- import the config file for credential details of database

\logging_config.py --- importing pathlib for making the actual path as parent and create log file to it log_rotation is done based on _dorollover() function it creates the files

\scheduler.py --- this the actual cron jobs process where it happened while importing connection from db, (schemaname,tablename and time) from config, importing logging_config, schedule module to set the automatic schedule with time intervals

    -   setting of loggers

    - insert_current_timestamp() - where it actually 
    happended the insertion of timestamp with 1 minute difference

    - create_partition() - where it create partitions to the current and future partition on the basis of 10 minutes gap

    - run_timestamp_job() - entry point of the insert_current_partition()

    - run_partition_job() - entry point of the create_partition()

    - run_scheduler() - where the actual cron jobs done with the help of schedule module so that it can directly implement the cron jobs for every 1 minute and 10 minute seperation

    -main() - the entry point of the run_scheduler so to excute all the code snippets properly!

\setup.py - setting up database with the imports from config, db for db name,schema and connection respectively

    - create_database() - create a db with autocommit while connecting to the default db

    - create_schema() - creating a schema and being verified

    - creat_table() - creating a table with id and unix_ts and do partitions based on timestamp and being verified

    - initialize_database() - an entry point for those three functions

    - main() - an entry point for initialize_database


### keep in build functions that are being used
- load_dotenv() - loading of db credentials with the help of dotenv import

- psycopy2.connect() - connecting to the db with the env variables from psycopg import

- RotatingFileHandler - a loggign import where it rotate the file with the help _doRollOver() so that log files can be created and segreted between old and new log file w.r.t the size

- time.perf_counter() - knows how much time the actual code will take execute/run

- int(time.time()) - converting the normal string unix_timestamp to integer unix_timestamp

- connection.cursor() - where it helps to tell the python to start the sql command

- connection.execute() - where we can able to execute the db commands in python scripts

- logging.getlogger() - we can pass the name of the logger that is show in the terminal

- schedule.every().minute.do() - assign the automated tasks so that it will do on it's own

- schedule.run_pending() - helps to check the pending jobs
