# Linux and Unix Basics

This folder contains my command-line learning notes.

## What I practiced

The notes cover commands such as:

```text
pwd   ls     cd     mkdir   touch
cp    mv     rm     cat     less
head  tail   grep   find    wc
sort  uniq   explorer.exe .
```

## Why this matters for application-side IIoT

Linux is common for servers, gateways, containers, and edge systems. I do not need to master system administration yet, but I do need to be comfortable moving around the file system, reading logs/files, finding files, and running commands.

## Learning flow

```text
Navigate
  ↓
Create / copy / move
  ↓
Read files
  ↓
Search text/files
  ↓
Inspect command-line output
```

The detailed notes are in [Learning_linux.md](Learning_linux.md), including the Unix-vs-Linux difference and the Windows trick (`explorer.exe .`) for opening the current folder from WSL.
