## log rotation - helps us to close the current log files,renaming it,starting a fresh log file and deleting the older logs so that it prevents one log file from growing forever

# size-based rotation: when we want to rotate after a log file reaches a certain size(rotatingfilehandler)
# time-based rotation: when we want to rortate on time intervals(timedrotatingfilehandler)
# signal-based rotation: when we deal with os signals commonly used with linux!


# Rotation 
- prevents one log file from growing indefinitely(time-based and size-based)
# compression
- tells us till how long should we compress it
# retention 
- tells us how long should we maintain the old logs
# centralized 
- can store in one centralized file
# Archiving
- helps to store them in archived mode so that later we can able to do analysis
# Deletion
- helps to determine when we can delete it

# Arguments:
    -   filename: where should the logs saved
    -   when: rotation based on time(seconds,minutes,hours,days,everymidnight,we can choose weekday,atTime as well)
